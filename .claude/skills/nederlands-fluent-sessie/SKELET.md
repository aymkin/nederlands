# Рамка и порядок слов: задания, оценка, запись

Читать, когда в раунде:

- карточка `gram_sk_*` — рамка, её `content` ссылается сюда;
- правило или паттерн порядка слов: `gram_lp_2.4` (`inversie`), `2.5`,
  `1.7`–`1.9`, `1.15` (глаголы в конце), `3.1` (`niet`), паттерны из таблицы
  «Запись».

Основа — `private/nl_thinking/onderzoek.md`, разделы 3, 4 и 6. Здесь только
правила и одна строка «почему».

## Слова

- **Сцена** — место, люди и цель говорящего. Стимул задания.
- **Тайник** — русский способ спрятать подлежащее: «можно», «нельзя», «надо»,
  «нужно», «есть/нет», «видно/слышно», безличное на -о («холодно», «жаль»), 3-е
  лицо мн. ч. без подлежащего («доставят»), «давай», окончание без местоимения
  («пойду»).
- **Рамка** — нидерландское подлежащее с личным глаголом на месте тайника:
  `Je mag …`, `Ze bezorgen …`, `Ik heb het koud`, `Er wordt …`.
- **Заготовка** — часть фразы, данная по-нидерландски. Не «хвост»: в итоге
  исследования хвост — это слот ④.
- **Слоты:**
  - ① `voorveld` — одно место перед личным глаголом;
  - ② `persoonsvorm` — личный глагол, в главном предложении всегда второй;
  - ③ `middenveld` — подлежащее при инверсии, местоимения, наречия, `niet`;
  - ④ `eindgroep` — инфинитивы, причастие, приставка, в `bijzin` и личный
    глагол;
  - ⑤ `achterveld` — предложные группы и придаточные после глаголов.
- **Обход** — ответ другим оборотом вместо рамки, исход ○.

## Что здесь главнее плагина

- `gram_sk_*` — задание «сцена → рамка», а не пропуск и не поиск ошибки.
- Оценка — по таблице ниже, за первую попытку. В сессии 031 оценили повтор после
  помощи — так больше не делать.
- Одно задание на повторение. «5 of 5» из `level-b1.md` складывается из
  повторений, а не из пяти фраз за раз.
- Шапка задания — как в плагине (номер, тип, дни, mastery, сложность), но без
  рамки, правила и id.

## Рецепт: сцена → рамка (`gram_sk_*`)

1. Первое предъявление (`total_reviews` = 0): сначала прайм — два нидерландских
   примера из `answer`, без перевода, потом сцена. Оценка такого задания — не
   выше 3: рамку только что показали.
2. Сцена — до двух строк, из жизни Alex, как и остальные задания, с явным «ты».
   Действие называй через цель: «ты хочешь включить радио».
3. Заготовка — всё вне слотов ①–② в готовом виде и порядке
   (`… hier niet roken?`), из слов дня, где получается. У рамок состояния —
   слово сказуемого (`koud`, `leuk`). Подлежащее и служебные слова самой рамки
   (`het` в `het regent`, `er`, `te`, `me`) не даются: их выбор и есть задание.
   Личный глагол не даётся, когда он сам рамка (`mag`, `moet`, `hoeft`, `zal`,
   `heb`); смысловой глагол даётся инфинитивом в скобках (`bezorgen`), иначе
   решений два.
4. Ответ — одна часть: заготовка плюс рамка, своих слов не больше шести.
5. С `mastery_level` 3 заготовки нет, только сцена: это тест «done».
6. Перед отправкой — проверка тайников: в сцене нет ни одного слова из списка
   выше. Подсказка «можно» тянет за собой кальку `het is mogelijk`.

## Рецепт: сборка по позиции

Вразброс даются словосочетания целиком (`mijn collega`, `de afspraak`),
строчными и без знаков. Решается только порядок частей. Это ступень 3, сколько
бы частей ни было в предложении.

- ② `inversie`: первый элемент дан отдельно, остальное вразброс. Тип первого
  элемента — `total_reviews` по модулю 5: 0 — время, 1 — место, 2 —
  дополнение-тема, 3 — наречие (`misschien`, `gelukkig`), 4 — придаточное,
  данное целиком. Инверсия у Alex выучена на отдельных словах (после `morgen`
  есть, после `Bij Danner` нет), поэтому тип меняется каждый раз.
- ④ `bijzin`: главная часть и союз даны (`Ik blijf thuis, omdat …`), придаточное
  вразброс. Союз — `total_reviews` по модулю 3: 0 — `omdat`, 1 — `dat`, 2 —
  `als`. При mastery 0–2 — один личный глагол, два (`kan komen` / `komen kan`,
  принимать оба) — с mastery 3. Изредка — второе сказуемое после `en` внутри
  `omdat`: на нём три записи журнала.
- ④ глаголы в конце главного: модальный + инфинитив, perfectum, отделяемая
  приставка.
- ③ `middenveld`: `niet` после определённого дополнения; слабое местоимение
  сразу за глаголом.
- ① `voorveld` по смыслу: тьютор даёт вопрос и краткий ответ
  (`Waar mag je niet fietsen? — Op de stoep.`), Alex печатает полный ответ, где
  краткий ответ стоит первым.
- Изредка — обратимая пара (`De hond ziet de kat`): роль задаёт позиция.

## Оценка

| Исход                                   | Score | quality |
| --------------------------------------- | ----- | ------- |
| ✔ при mastery 3 и выше                  | 10    | 5       |
| ✔                                       | 8–9   | 4       |
| ✔, но «не уверен», или после прайма     | 6–7   | 3       |
| ○ обход: верный, но другой оборот       | 4–5   | 2       |
| ✘ калька, сломанный скелет, не тот слот | 2–3   | 1       |
| молчание, «не знаю»                     | 0–1   | 0       |

- 5 — только при mastery 3 и выше: «легко» на новой карточке уводит её на
  недели.
- В точность сессии идёт только ✔. Если считать обход успехом, рамка, которую
  Alex обходит, за пять повторов уйдёт в `low`.
- Обход в шаблоне — верхняя строка ✅ и без ❌-блока (форма верна), но в строке
  оценки — «обход»: анализатор не примет его за ошибку формы.
- Тяжесть ошибки — 🟡, пока смысл цел; 🔴 — только когда смысл сломан.
- При ✘ и при ○ — подсказка до образца (`fluent-feedback-formatter`, «Prompt
  before recast»). Что в ней:
  - рамка — один вопрос: «Кто здесь подлежащее: ты сам, люди вообще, кто-то
    неназванный — или это твоё состояние?»;
  - порядок — имя слота: «Где `persoonsvorm`?», «Что уходит в конец?», «Где
    `niet` относительно дополнения?».
- После ✘ и ○ у рамки — строка сопоставления и регистр сразу за «Correct
  version»: «по-русски тайник „можно“ → рамка `je mag`; так говорят; на вывеске
  — `Hier mag niet gerookt worden`». Регистровый вариант — третий пример из
  `answer` карточки. Исход (✔/✘/○) — в комментарии строки оценки.

## Запись (`errors[]`, категория `grammar`)

| Что                                      | `pattern_id`                                             |
| ---------------------------------------- | -------------------------------------------------------- |
| рамка                                    | id карточки (`gram_sk_1.3`): второй карточки не появится |
| ② нет инверсии                           | `grammar_hoofdzin_inversie`                              |
| ④ глагол не в конце                      | `grammar_word_order_verb_final`                          |
| ④ наоборот: глагол в конце после `want`  | `grammar_want_vs_omdat`                                  |
| ④ второе сказуемое после `en` в `bijzin` | `grammar_bijzin_en_conjunct`                             |
| ④ отделяемая приставка                   | `grammar_scheidbare_werkwoorden`                         |
| ③ `niet`                                 | `grammar_niet_before_destination`                        |
| ③ время перед дополнением                | `grammar_middlefield_time_before_object`                 |
| ③ местоимение                            | `grammar_pronoun_before_adverb`                          |
| `te`                                     | `grammar_om_te_construction`, `grammar_hoeven_negative`  |

`omdat_verb_final` дублирует `grammar_word_order_verb_final`: новые записи — во
второй. Обход (○) в `errors[]` не пишется: это не ошибка формы, его ловят оценка
2 и субботняя проба.

## Задание готово, когда

- сцена прошла проверку тайников;
- решение одно: заготовка или данные слова закрывают остальное;
- шапка не называет рамку;
- после ответа назван исход ✔/✘/○ и quality по таблице, а при ✘ и ○ — слот или
  рамка.

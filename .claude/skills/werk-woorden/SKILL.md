# Werk-woorden: почта → индекс лемм → 5 карточек

Всё, что создаётся здесь, лежит в `werk/` и уходит на публичный GitHub Pages.
Поэтому в репо попадает только **обезличенный** текст. Счёт, выбор и TSV
выполняет `scripts/werk_woorden.py`, лемматизацию делаешь ты.

## 1. Почта

Chrome, `outlook.cloud.microsoft/mail/inbox`: письма, пришедшие после
`laatste_run` из `werk/lemmas.json`. Текст письма бери через `javascript_tool`:
`innerText` у `[data-app-section="ConversationContainer"]`, пробелы сжаты. Вывод
режется примерно на 1400 символах, поэтому длинное письмо читай срезами.

Бери письма на нидерландском, и автоматические тоже. Отбрасывай подпись, цитаты
предыдущих писем треда и шаблон Teams-приглашения.

**Готово**, когда каждое новое письмо либо прочитано целиком, либо отброшено с
причиной (английское, пустое).

## 2. Обезличить → `werk/mail/`

Файл `werk/mail/YYYY-MM-DD_<тема>.md`, дата — дата получения, во frontmatter
`ontvangen` и `soort` (кто пишет, роль без имени). Обезличить значит:

- люди → вымышленные имена; компании, продукты, проекты, внутренние сокращения →
  вымышленные (`Kaartnet`, `RegioRail`, `Reispas`, `Reiskompas` уже в ходу —
  переиспользуй);
- даты событий, суммы, сроки, станции, адреса, телефоны, ссылки → другие
  правдоподобные значения;
- терминология (`instaptarief`, `looncomponent`, `op productie testen`) и манера
  (обращение, длина фраз, англицизмы вроде `meeting`, `switchen`) остаются;
- явные опечатки исправляй: предложение станет примером на карточке.

**Готово**, когда в файле нет ни одного реального имени, названия, числа или
места из оригинала.

## 3. Леммы → `merge`

Выдай VOORKOMENS.json (схема — `werk_woorden.py --help`): запись на каждое
словоупотребление, `zin` — предложение из обезличенного файла. Бери лексические
слова: существительные, глаголы, прилагательные, наречия со своим значением
(`helaas`, `alsnog`, `vooraf`). Закрытые классы пропускай: lidwoorden,
voornaamwoorden, voorzetsels, voegwoorden, hulp- и modale werkwoorden, а также
вымышленные имена. Разделимый глагол — одна лемма (`neem … mee` → `meenemen`).

```bash
python3 scripts/werk_woorden.py merge <scratchpad>/voorkomens.json
```

Прогон засчитывается и в день без новых писем: `merge` пустого `[]` ставит
`laatste_run`.

**Готово**, когда `merge` напечатал ✅, и каждое письмо шага 2 вошло в него.

## 4. Выбор дня

```bash
python3 scripts/werk_woorden.py kies -n 10
```

Сверху — частые леммы со `status: nieuw`. Поле `cursus` показывает, что слово
было в woordenlijst курса: это подсказка, не доказательство знания. Лемму,
которую Alex уверенно знает на A2, убирай командой `markeer bekend <лемма>…`.
Бери 5. Если лемма в письме живёт внутри устойчивого выражения, карточка учит
выражение (`opnemen` → `contact opnemen met`).

**Готово**, когда выбрано ровно 5 лемм, а каждая пропущенная над ними помечена
`bekend`.

## 5. Карточки

KAARTEN.json (схема — `werk_woorden.py --help`). `word` — с lidwoord. `zin` —
предложение из письма, укороченное до одной мысли, если оно длинное. `vertaling`
— 1–2 русских значения с пометой контекста.

```bash
python3 scripts/werk_woorden.py kaarten <scratchpad>/kaarten.json --audio --anki
```

`--anki` импортирует TSV дня через AnkiConnect в `Frequentie::Werk`; Anki должен
быть запущен. Дубль по полю `Word` пропускается, повторный запуск безопасен.

**Готово**, когда скрипт напечатал `📥 Anki: +5`, а Alex получил список пяти
слов.

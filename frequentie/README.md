# Frequentie — частотное ядро нидерландского (колода Alex)

Колода вне курсов: слова идут в порядке консенсусного частотного ранга, не по
темам учебника. Почему так и откуда числа —
`other/language_learning_methods/eroshev_frequentie_methode.md`; план и метрики
— `daily/frequentie_2026/plan.md`.

## Файлы

| Файл                      | Что внутри                                     |
| ------------------------- | ---------------------------------------------- |
| `functiewoorden_anki.txt` | ~70 служебных слов, направление NL → RU        |
| `kern_0001-0100_anki.txt` | партия 1 — 21 карточка, ранги 116–481          |
| `kern_partij02_anki.txt`  | партия 2 — 100 карточек, ранги 252–818         |
| `kern_partij03_anki.txt`  | партия 3 — 100 карточек, ранги 823–1187        |
| `README.md`               | этот файл: note type, формат TSV, дневной цикл |

Нумерация файлов — по **партиям**, не по диапазону рангов: партия собирается из
пробела по возрастанию консенсусного ранга, а он пересчитывается, поэтому
диапазон у партии плавающий. Первая партия названа `0001-0100` до того, как это
выяснилось; переименовывать не стали — имя ничего не ломает.

**Теги несут день:** `frequentie::kern::partij02` плюс
`frequentie::kern::dagNN`. Карточки в файле идут по дням, значит и Anki при
импорте расставит их в этом порядке. День в теге нужен, чтобы примеры дня
совпадали с грамматическими правилами этого дня (`grammatica/README.md`).

Колоды генерируются только после гейта недели 2 плана (см. план, раздел 3).

## Note type «Frequentie NL» (создать в Anki один раз)

Существующие типы не подходят: `LINK Vocabulary` показывает нидерландское слово
спереди (направление NL → RU) и не имеет поля Audio; `Language Islands`
двусторонний (второй шаблон — лишняя работа, Mondria & Wiersma 2004) и без
примера. Новый тип — одна карточка, одно направление.

**Tools → Manage Note Types → Add → Add: Basic → имя `Frequentie NL`.** Затем
**Fields** — переименовать/добавить в этом порядке:

| #   | Поле                 | Содержимое                                     |
| --- | -------------------- | ---------------------------------------------- |
| 1   | `Word`               | лемма с артиклем: `het gebruik`, `vertellen`   |
| 2   | `Rank`               | консенсусный ранг, число                       |
| 3   | `Example`            | одно короткое нидерландское предложение        |
| 4   | `Translation`        | русский перевод (1–2 значения, не статья)      |
| 5   | `TranslationExample` | перевод примера                                |
| 6   | `Audio`              | `[sound:freq_vertellen.mp3]` — озвучка примера |

**Cards → шаблон «Card 1»** (единственный):

Front:

```html
<div class="direction">🇷🇺 → 🇳🇱</div>
<div class="translation">{{Translation}}</div>
<div class="context">{{TranslationExample}}</div>
```

Back:

```html
{{FrontSide}}
<hr id="answer" />
<div class="word">{{Word}}</div>
<div class="example">{{Example}}</div>
{{Audio}}
<div class="rank">#{{Rank}}</div>
```

Styling:

```css
.card {
  font-family: -apple-system, Helvetica, sans-serif;
  font-size: 22px;
  text-align: center;
}
.direction {
  font-size: 14px;
  color: #999;
}
.translation {
  font-size: 30px;
  font-weight: bold;
  margin-top: 12px;
}

  font-size: 18px;
  color: #666;
  margin-top: 6px;
}

  font-size: 32px;
  font-weight: bold;
  color: #1a5fb4;
  margin-top: 12px;
}

  margin-top: 6px;
}

  font-size: 12px;
  color: #bbb;
  margin-top: 14px;

```

Почему именно так:

- **Русский пример спереди** — контекст, а не подсказка: он показывает, какое из
  значений имеется в виду (чайник-для-заварки против чайника-для-кипятка у
  Ерошева). Без него карточка раздражает ложными «ошибками».
- **Нидерландский пример и звук только сзади** — Barcroft 2004: при первом
  кодировании формы внимание не размазывать.
- **Одна карточка.** Обратная (NL → RU) не окупается: 49 % против 48 % при вдвое
  большей работе.
- **Ранг мелким сзади** — как у Ерошева: видно, насколько частое слово.

## Формат TSV для импорта

```
#separator:tab
#html:true
#notetype:Frequentie NL
#deck:Frequentie::Kern
#columns:Word	Rank	Example	Translation	TranslationExample	Audio	Tags
#tags column:7
```

**Имя mp3 — по лемме, без ранга.** Та же причина: `freq_0101_misschien.mp3`
пришлось бы переименовывать при каждом пересчёте ранга, а лемма не меняется.
Исправлено 2026-09-14 вместе с порядком полей.

**Почему `Word` первым, а не `Rank`.** Anki определяет дубликаты по **первому
полю**: при повторном импорте строка с уже существующим первым полем обновляет
заметку, а не создаёт вторую. Ранг у нас временный — сейчас он из одних
субтитров, после консенсусного ранга (план, 2.3) числа сдвинутся. Если первым
полем стоит `Rank`, такой пересчёт превращает каждую карточку в новую: 1000
дублей и потерянные интервалы. Лемма стабильна, поэтому ключ — она. Порядок
исправлен 2026-09-14, до создания типа в Anki; позже он стоил бы пересборки
колоды.

Колонки разделены **литеральными табами** (`.prettierignore` уже исключает
`_anki.txt`). Теги: `frequentie::kern::0001-0100`, для служебных —
`frequentie::functiewoorden`. Директива `#notetype:` требует, чтобы тип уже
существовал — отсюда ручной шаг выше.

Служебные слова (`functiewoorden_anki.txt`) идут тем же типом, но с полями
`Translation` спереди, как и остальные: узнавания для них достаточно, однако
отдельный тип ради 70 карточек не стоит второго шаблона. Если направление NL →
RU для них окажется важным — завести второй note type, не второй шаблон.

## Дневной цикл: утро Anki → день Fluent

1. **Утро.** Anki, колода `Frequentie`: сначала повторения, потом новые (норма
   из плана: 20 → 15 в день, понедельник–суббота). Карточка раздражает третий
   раз — в архив (suspend), не мучиться. **Воскресенье — выходной по новым:**
   лимит новых 0, повторения идут как обычно (пропущенный день повторений отдаёт
   очередь в понедельник вдвое). В Anki это Deck Options → отдельный preset или
   ручное «New cards/day = 0» на воскресенье; проще — просто не нажимать
   «новые».
2. **Мостик.**
   `python3 scripts/anki_vandaag.py --out private/frequentie/vandaag.md` —
   скрипт читает копию коллекции и выписывает слова, чьи карточки получили
   первое повторение сегодня. Файл в `private/`, не публикуется.
3. **День.** `/fluent-review` как обычно. Правило для Fluent (в `CLAUDE.md`,
   Tutor Mode): если `private/frequentie/vandaag.md` датирован сегодня,
   упражнения на `grammar_rule` строятся на этих словах — они попадают в
   предложения на инверсию, `omdat`-порядок, perfectum и т.д. Слова **не**
   попадают в `new_vocabulary[]`: их интервалы ведёт Anki, второй SRS на то же
   слово — двойная работа без прибавки.

Так одно и то же слово в один день встречается трижды в разном качестве:
извлечение формы по-русски (Anki), пример со звуком (Anki, оборот), и
употребление внутри грамматической конструкции (Fluent). Это ровно «качество
встречи», которое у Uchihara 2019 весит больше числа встреч.

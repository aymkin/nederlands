### 1.1 · Het werkwoord, presens, singularis (глагол, настоящее время, ед. число)

**Regel:** In de singularis maak je het werkwoord van de **stam**.
**По-русски:** В единственном числе форма глагола строится от **основы** (stam).
Основа = инфинитив без `-en` (`werken → werk`).

- `ik` + основа → `ik werk`
- `je / u / hij / ze` + основа + **-t** → `je werkt`

| persoon | werken | sporten | wonen | spellen |
| ------- | ------ | ------- | ----- | ------- |
| ik      | werk   | sport   | woon  | spel    |
| je      | werkt  | sport   | woont | spelt   |
| u       | werkt  | sport   | woont | spelt   |
| hij     | werkt  | sport   | woont | spelt   |
| ze      | werkt  | sport   | woont | spelt   |

**⚠️ Let op (правописание основы):**

- `sporten → sport`: основа уже кончается на `-t`, второй `-t` не пишем →
  `je sport` (не «sportt»).
- `wonen → woon`: долгий гласный. В закрытом слоге он пишется удвоенно, поэтому
  `ik woon` (см. правило 7.1).
- `spellen → spel`: двойная согласная в основе становится одиночной → `ik spel`
  (см. правило 7.2).

**Voorbeelden / Примеры:**

- `Ik werk in Rotterdam.` — Я работаю в Роттердаме.
- `Hij komt uit China.` — Он из Китая.
- `Ze woont in Nederland.` — Она живёт в Нидерландах.
- `U spelt uw naam.` — Вы произносите своё имя по буквам.

**Частая ошибка:** пропуск `-t` у `je / hij / ze` (`hij werk` ✗ → `hij werkt`
✓).

### 1.2 · Het werkwoord, presens, singularis + 'je' (инверсия с «je»)

**Regel:** Staat `je` **ná** het werkwoord, dan valt de **-t** weg.
**По-русски:** Если `je` стоит **после** глагола (в вопросе или при инверсии),
окончание **-t исчезает**.

| gewone zin                  | vraag / inversie            |
| --------------------------- | --------------------------- |
| Je **werkt** in Amsterdam.  | **Werk** je in Amsterdam?   |
| Je **woont** in Utrecht.    | **Woon** je in Utrecht?     |
| Je **sport** in Amersfoort. | **Sport** je in Amersfoort? |

**⚠️ Let op:** `werkt → werk` — только с местоимением `je/jij`. С `u`, `hij`,
`ze` окончание `-t` сохраняется: `Werkt u?`, `Werkt hij?`.

**Voorbeelden / Примеры:**

- `Waar werk je?` — Где ты работаешь?
- `Woon je hier?` — Ты здесь живёшь?

**Подсказка:** правило `-t` отпадает **только для `je`** — это самая частая
ошибка на этом уровне.

---

### 1.3 · Het werkwoord, presens, pluralis (глагол, настоящее время, мн. число)

**Regel:** In de pluralis is het werkwoord gelijk aan de **infinitief**.
**По-русски:** Во множественном числе форма глагола совпадает с **инфинитивом**
(`werken`, `sporten`, …) — для `we`, `jullie` и `ze`.

| persoon | werken | sporten | wonen | spellen |
| ------- | ------ | ------- | ----- | ------- |
| we      | werken | sporten | wonen | spellen |
| jullie  | werken | sporten | wonen | spellen |
| ze      | werken | sporten | wonen | spellen |

**Enkelvoud → meervoud (ед. → мн.):**

- `Anna werkt.` → `Ze werkt.` (одна) / `Anna en David werken.` → `Ze werken.`
  (двое)

**Voorbeelden / Примеры:**

- `We wonen in Almere.` — Мы живём в Алмере.
- `Jullie spreken goed Nederlands.` — Вы хорошо говорите по-нидерландски.

---

### 1.5 · Het werkwoord 'hebben', presens (глагол «иметь»)

**Regel:** `hebben` is een veelgebruikt werkwoord met eigen vormen.
**По-русски:** `hebben` = «иметь / есть у…». Спряжение частично нерегулярное —
запомните формы.

| singularis                | pluralis          |
| ------------------------- | ----------------- |
| ik **heb**                | we **hebben**     |
| je **hebt** (→ `heb je?`) | jullie **hebben** |
| u **hebt / heeft**        | ze **hebben**     |
| hij / ze **heeft**        |                   |

**Enkelvoud → meervoud:** `Anna heeft een kind.` → `Ze heeft een kind.` /
`Anna en David hebben een kind.` → `Ze hebben een kind.`

**⚠️ Let op:** при инверсии `je hebt → heb je?` (как в правиле 1.2).

**Voorbeelden / Примеры:**

- `Ik heb een vraag.` — У меня есть вопрос.
- `Heb je tijd?` — У тебя есть время?
- `Hij heeft twee kinderen.` — У него двое детей.

---

### 1.6 · Het werkwoord 'zijn', presens (глагол «быть»)

**Regel:** `zijn` is onregelmatig. **По-русски:** `zijn` = «быть». Полностью
нерегулярный глагол, формы нужно выучить наизусть.

| singularis                | pluralis        |
| ------------------------- | --------------- |
| ik **ben**                | we **zijn**     |
| je **bent** (→ `ben je?`) | jullie **zijn** |
| u **bent**                | ze **zijn**     |
| hij / ze **is**           |                 |

**Enkelvoud → meervoud:** `Anna is in Haarlem.` → `Ze is in Haarlem.` /
`Anna en David zijn in Haarlem.` → `Ze zijn in Haarlem.`

**Voorbeelden / Примеры:**

- `Ik ben Alex.` — Я Алекс.
- `Ben je nieuw hier?` — Ты здесь новенький?
- `We zijn thuis.` — Мы дома.

### 2.4 · De zin met één werkwoord (предложение с одним глаголом)

**Regel:** Het werkwoord (de persoonsvorm) staat op de **tweede plaats**.
**По-русски:** В простом утвердительном предложении спрягаемый глагол стоит на
**втором месте**. На первом месте может быть подлежащее или другой член
предложения.

| 1   | 2 (werkwoord) | 3      | de rest            |
| --- | ------------- | ------ | ------------------ |
| Ik  | kook          | pasta. |                    |
| Je  | kookt         | pasta. |                    |
| We  | koken         | pasta  | in het weekend.    |
| Ze  | koken         | pasta  | in het restaurant. |

**Voorbeelden / Примеры:**

- `Ik werk in Amsterdam.` — Я работаю в Амстердаме.
- `In het weekend koken we pasta.` — По выходным мы готовим пасту. _(на 1-м
  месте — обстоятельство, глагол всё равно на 2-м месте, подлежащее — после
  глагола.)_

**Подсказка:** это ключевое правило нидерландского порядка слов — «глагол на
втором месте» (V2).

---

### 2.6 · De vraagzin met een vraagwoord (вопрос с вопросительным словом)

**Regel:** Volgorde: **vraagwoord – werkwoord – subject – rest**. **По-русски:**
В вопросе с вопросительным словом порядок такой: вопросительное слово → глагол →
подлежащее → остальное.

| 1 vraagwoord | 2 werkwoord | 3 subject  | 4 rest   |
| ------------ | ----------- | ---------- | -------- |
| Wie          | ben         | je?        |          |
| Wat          | is          | het adres? |          |
| Waar         | komen       | jullie     | vandaan? |

**Vraagwoorden (вопросительные слова):** `wie` (кто), `wat` (что), `waar` (где),
`wanneer` (когда), `hoe` (как), `waarom` (почему), `welk(e)` (какой).

**Voorbeelden / Примеры:**

- `Waar werk je?` — Где ты работаешь?
- `Hoe heet u?` — Как вас зовут?

### 6.1 · Het personaal pronomen als subject — 1e en 2e persoon (личные местоимения-подлежащие, 1-е и 2-е лицо)

**Regel:** Personaal pronomen als subject, singularis en pluralis.
**По-русски:** Личные местоимения в роли подлежащего.

|                    | singularis      | pluralis           |
| ------------------ | --------------- | ------------------ |
| 1e persoon         | `ik` (я)        | `we` (мы)          |
| 2e persoon         | `je` (ты)       | `jullie` (вы, мн.) |
| 2e persoon beleefd | `u` (Вы, вежл.) | `u`                |

**⚠️ Let op:** `u` — вежливое «Вы» и для одного, и для нескольких человек;
глагол при `u` — в форме ед. числа: `Werkt u hier?`.

---

### 6.2 · Het personaal pronomen als subject — 3e persoon (личные местоимения-подлежащие, 3-е лицо)

**Regel:** 3e persoon, singularis en pluralis. **По-русски:** Местоимения 3-го
лица.

| singularis |                                    | pluralis   |                                                     |
| ---------- | ---------------------------------- | ---------- | --------------------------------------------------- |
| `hij` (он) | Dit is Ali. **Hij** is een man.    | `ze` (они) | Dit zijn Ali en Sarah. **Ze** zijn getrouwd.        |
| `ze` (она) | Dit is Sarah. **Ze** is een vrouw. | `ze` (они) | Dit zijn Mohamed, Adam en Sofia. **Ze** eten pasta. |

**⚠️ Let op:** `ze` = и «она» (ед.), и «они» (мн.). Число понятно по форме
глагола: `ze **is**` (она) ↔ `ze **zijn**` (они).

---

### 6.3 · Het personaal pronomen als subject (herhaling) (повторение)

**Regel:** Herhaling van 6.1 en 6.2 — alle persoonlijke voornaamwoorden samen.
**По-русски:** Повторение правил 6.1 и 6.2 — все личные местоимения-подлежащие
вместе.

|            | singularis             | pluralis       |
| ---------- | ---------------------- | -------------- |
| 1e persoon | `ik`                   | `we`           |
| 2e persoon | `je` / `u`             | `jullie` / `u` |
| 3e persoon | `hij` (он), `ze` (она) | `ze` (они)     |

**Volledig voorbeeld / Пример «в сборе»:**

- `Ik ben Alex. Je bent mijn buurman. Hij werkt in Utrecht. We wonen in Hilversum. Jullie komen morgen. Ze zijn thuis.`

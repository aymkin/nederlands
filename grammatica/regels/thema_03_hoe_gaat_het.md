### 1.4 · Het werkwoord, presens, singularis en pluralis — herhaling (повторение спряжения)

**Regel:** Herhaling: presens in enkelvoud én meervoud. **По-русски:**
Повторение настоящего времени — единственное и множественное число вместе
(правила 1.1–1.3).

| singularis              | pluralis      |
| ----------------------- | ------------- |
| ik werk                 | we werken     |
| je werkt (→ `werk je?`) | jullie werken |
| u werkt                 | ze werken     |
| hij / ze werkt          |               |

**Kort / Кратко:**

- `ik` → основа; `je/u/hij/ze` → основа + `-t`; `je` после глагола → без `-t`.
- множественное число (`we/jullie/ze`) = инфинитив.

### 1.14 · Het presens gebruiken voor de toekomst (настоящее время для будущего)

**Regel:** Je kunt het **presens** gebruiken om over de **toekomst** te praten,
vaak met een tijdwoord (`morgen`, `zaterdag`, `volgende maand`). **По-русски:**
Настоящее время можно использовать для **будущего** — обычно вместе со словом
времени (`morgen` — завтра, `zaterdag` — в субботу, `volgende maand` — в
следующем месяце). Отдельного будущего времени, как правило, не нужно.

| nu (сейчас)             | toekomst (будущее)                      |
| ----------------------- | --------------------------------------- |
| Ik ben thuis.           | Ik ben **morgen** thuis.                |
| Anna doet boodschappen. | Anna doet **zaterdag** boodschappen.    |
| We hebben een kind.     | We krijgen **volgende maand** een kind. |

**Voorbeelden / Примеры:**

- `Ik bel je straks.` — Я тебе скоро позвоню.
- `Volgende week begin ik met een cursus.` — На следующей неделе я начну курс.

### 1.16 · Het werkwoord, de imperatief (повелительное наклонение)

**Regel:** De imperatief heeft de **ik-vorm** (`kom`, `luister`, `ga`). De zin
heeft **geen subject** en de imperatief staat op de **eerste plaats**.
**По-русски:** Повелительная форма (приказ, просьба, инструкция) совпадает с
формой `ik` (основа глагола): `kom`, `luister`, `ga`. Подлежащего **нет**,
глагол — на **первом месте**.

**Voorbeelden / Примеры:**

- `Kijk!` — Смотри!
- `Kom hier!` — Иди сюда!
- `Luister naar de docent!` — Слушай(те) преподавателя!
- `Ga zitten.` — Садись / садитесь.

**⚠️ Let op — вежливее и мягче:** слова `even`, `maar`, `eens` смягчают приказ:

- `Kom **even** hier.` — Подойди-ка сюда.
- `Schrijf **maar** een appje.` — Напиши просто сообщение.
- `Kijk **eens** hier.` — Взгляни-ка сюда.

**Подсказка:** для очень вежливой просьбы часто добавляют
`alstublieft/alsjeblieft`: `Gaat u zitten, alstublieft.`

### 5.2 · Het lidwoord, bepaald en onbepaald: de/het vs een (определённый и неопределённый артикль)

**Regel:** Weet je nog niets (nieuwe informatie)? → gebruik **`een`**. Weet je
al wel iets (bekend)? → gebruik **`de`** of **`het`**. **По-русски:**
Неопределённый артикль `een` — для **новой** информации (предмет упоминается
впервые). Определённый `de/het` — когда предмет уже **известен** (упоминался
раньше или понятен из контекста).

| nieuwe informatie (`een`) | al bekend (`de/het`) |
| ------------------------- | -------------------- |
| een huis                  | het huis             |
| een banaan                | de banaan            |
| een baby                  | de baby              |

**Voorbeeld in tekst / Пример в тексте:**

- `Ik heb **een** huis. **Het** huis heeft een keuken.` — У меня есть дом. У
  (этого) дома есть кухня.
- `David eet **een** banaan. **De** banaan is lekker.` — Давид ест банан. Банан
  вкусный.

**⚠️ Let op:** выбор `de` или `het` зависит от самого слова (см. 5.1); `een`
одинаково для любых слов, а во мн. числе неопределённого артикля нет
(`een huis → huizen`).

### 6.7 · Het possessief pronomen, singularis (притяжательные местоимения, ед. число)

**Regel:** Possessief pronomen = van wie is iets. **По-русски:** Притяжательные
местоимения показывают принадлежность («чей?»).

| subject | possessief | пример                          |
| ------- | ---------- | ------------------------------- |
| ik      | **mijn**   | Ik zoek **mijn** tas.           |
| je      | **je**     | Dit is **je** tas.              |
| u       | **uw**     | Dit is **uw** tas, meneer.      |
| hij     | **zijn**   | Dit is **zijn** tas (van Ali).  |
| ze      | **haar**   | Dit is **haar** tas (van Anna). |

**⚠️ Let op:** не путайте `je` (притяжат. «твой») и `je` (местоимение-подлежащее
«ты»): `Je (ты) zoekt je (твою) tas.`

**Voorbeelden / Примеры:**

- `Wat is uw achternaam?` — Как ваша фамилия?
- `Haar man werkt in Amsterdam.` — Её муж работает в Амстердаме.

---

### 6.8 · Het possessief pronomen, pluralis (притяжательные местоимения, мн. число)

**Regel:** Possessief pronomen in de pluralis. **По-русски:** Притяжательные
местоимения для «мы / вы / они».

| subject | possessief | пример                  |
| ------- | ---------- | ----------------------- |
| we      | **onze**   | Dit is **onze** poes.   |
| jullie  | **jullie** | Is dat **jullie** poes? |
| ze      | **hun**    | Dat is **hun** auto.    |

**⚠️ Let op:** `jullie` — и подлежащее («вы»), и притяжательное («ваш»):
`Jullie hebben jullie sleutels.`

---

### 6.9 · Het possessief pronomen, 1e persoon pluralis: ons / onze (наш)

**Regel:** Gebruik **`ons`** alleen bij een **`het`-woord in het enkelvoud**. In
alle andere gevallen: **`onze`**. **По-русски:** «Наш» имеет две формы. `ons` —
только перед **het-словом в единственном числе**. Во всех остальных случаях
(de-слова и любое множественное число) — `onze`.

|                 | singularis                  | pluralis                   |
| --------------- | --------------------------- | -------------------------- |
| **de**-woorden  | onze vriend, onze appel     | onze vrienden, onze appels |
| **het**-woorden | **ons** brood, **ons** dorp | onze broden, onze dorpen   |

**Kort / Кратко:** `ons` = het-слово ед. ч. (`ons huis`, `ons kind`). Всё
остальное = `onze`.

**Voorbeelden / Примеры:**

- `Ons huis is klein.` — Наш дом маленький. _(het huis → ons)_
- `Onze buurvrouw is aardig.` — Наша соседка добрая. _(de buurvrouw → onze)_

### 6.11 · Het possessief pronomen, 2e persoon singularis, zonder en met accent: je / jouw (твой)

**Regel:** De **neutrale** vorm is **`je`**. **`jouw`** heeft **accent** (nadruk
of contrast). **По-русски:** «Твой» имеет две формы. Нейтральная — `je`. Ударная
— `jouw` — когда нужно **подчеркнуть** или **противопоставить** («именно твой»).

| zonder accent (нейтр.)          | met accent (ударная)                             |
| ------------------------------- | ------------------------------------------------ |
| Julia, **je** jas ligt hier.    | Is dit mijn telefoon of **jouw** telefoon?       |
| Adam, wat is **je** achternaam? | Mijn moeder en **jouw** moeder wonen in Utrecht. |

**Подсказка:** по умолчанию используйте `je`; `jouw` — только для
акцента/контраста. Не путайте с `jou` (без `-w`) — это уже дополнение
(«тебе/тебя»), другое слово.

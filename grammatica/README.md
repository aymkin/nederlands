# Grammatica — грамматический трек Alex

Грамматика ведущая, слова нанизываются на неё. Решение Alex 2026-09-16 после
сессии, где упражнения на свободную продукцию оказались на две ступени выше его
уровня (журнал: `daily/frequentie_2026/plan.md`, раздел 5).

## Почему трек вообще появился

Замер 56 паттернов ошибок (`private/grammatica_onderzoek/metingen_lokaal.md`):

| тип        | срабатываний | доля |
| ---------- | ------------ | ---- |
| морфология | 45           | 42%  |
| орфография | 24           | 23%  |
| лексика    | 19           | 18%  |
| синтаксис  | 17           | 16%  |

Частотное ядро закрывает лексику — 18 % проблемы. Остальные 82 % лежат в
грамматике и орфографии, и их не закрывает ничто.

## Файлы

| Файл                    | Что внутри                                  |
| ----------------------- | ------------------------------------------- |
| `regels/thema_01…04.md` | свод правил Link+ по темам 1–4 (34 правила) |
| `README.md`             | этот файл                                   |

Источник: linkplus.linkmethode.nl → Thema N → Grammatica. Формат каждого
правила: `### N.M · Titel (русская расшифровка)`, затем `**Regel:**` по-
нидерландски, `**По-русски:**`, таблица, `**⚠️ Let op**`,
`**Voorbeelden / Примеры:**`, `**Частая ошибка:**`. Парсер
`scripts/grammatica_fluent.py` опирается на эти заголовки — меняя формат,
проверь `--dry-run`.

## Таксономия правил

| Группа | Тема                       | Правил в темах 1–4 |
| ------ | -------------------------- | ------------------ |
| `1.x`  | het werkwoord — глагол     | 12                 |
| `2.x`  | de zin — предложение       | 7                  |
| `6.x`  | het pronomen — местоимение | 8                  |
| `3.x`  | negatie — отрицание        | 2                  |
| `5.x`  | het lidwoord — артикль     | 2                  |
| `7.x`  | de spelling — орфография   | 2                  |
| `4.x`  | het substantief            | 1                  |

Пропуски `1.10–1.13`, `6.5`, `6.6`, `6.10` — они в темах 5 и дальше, свод
пополняется по мере выгрузки.

## Порядок подачи и одна перестановка

По умолчанию — порядок учебника: по теме, внутри темы по номеру правила (это в
точности порядок обзорных таблиц в каждой теме).

**Исключение: `7.1` и `7.2` подняты в самое начало.** Причина измерена, а не
выбрана: правило `1.1` (основа = инфинитив без `-en`) ссылается на `7.1` и `7.2`
за `wonen → woon` и `spellen → spel`, а `4.1` (множественное число) ссылается на
`7.1` за `naam → namen`. При исходном порядке `7.1`/`7.2` стоят предпоследними —
три ссылки вперёд. После перестановки ссылок вперёд **ноль**.

Побочно закрывается самая частая орфографическая ошибка Alex
(`spelling_vowel_doubling`, 6 срабатываний) и его собственный запрос на урок про
границу слога.

Список перестановки — `VOORRANG` в `scripts/grammatica_fluent.py`.

## Одна карточка на правило — зачем именно так

Не на пример, не на упражнение — **на правило**. Тогда у каждого правила копится
собственная `review_history`, то есть число попыток. Это знаменатель, которого
нет в `mistakes-db`: «ошибся 7 раз» ничего не значит без «из скольки».
Диагностика по правилам (план, раздел 2) получает его бесплатно.

## Дневной цикл

1. **Anki** — повторения частотной колоды, 10 новых слов (снижено с 20 на время
   трека).
2. **Мостик** —
   `python3 scripts/anki_vandaag.py --out private/frequentie/vandaag.md`.
3. **Fluent** — `/fluent-review`. В очереди 2 новых правила + повторения.
   Упражнения строятся **на правиле**, наполнение берётся из слов дня.

Ступень задания — пропуск или исправление одной ошибки, не свободная продукция:
правило должно быть единственной трудностью. Лестница ступеней — в
`daily/frequentie_2026/plan.md`, раздел 3.

## Управление объёмом

Fluent не настраивается — расписание живёт в базе:

```bash
python3 scripts/grammatica_fluent.py --regels grammatica/regels --per-dag 2 --dry-run
python3 scripts/grammatica_fluent.py --regels grammatica/regels --per-dag 2
```

`--per-dag` раскладывает `due_date` по рабочим дням (воскресенье пропускается).
Скрипт идемпотентен: правило, уже заведённое в базу, не трогается — так что
новые темы доливаются тем же вызовом.

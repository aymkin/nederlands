# Thema 16: We Hebben een Probleem — Grammatica

## 2.22 Voltooide tijd scheidbare werkwoorden met hebben: ik heb opgeruimd

### Regel

Scheidbare werkwoorden in de voltooide tijd: **ge-** komt **tussen** de twee
delen:

| Werkwoord       | Voltooid deelwoord |
| --------------- | ------------------ |
| op**ruimen**    | op**ge**ruimd      |
| klaar**maken**  | klaar**ge**maakt   |
| in**pakken**    | in**ge**pakt       |
| uit**nodigen**  | uit**ge**nodigd    |
| op**halen**     | op**ge**haald      |
| af**zeggen**    | af**ge**zegd       |
| aan**vragen**   | aan**ge**vraagd    |
| terug**sturen** | terug**ge**stuurd  |
| schoon**maken** | schoon**ge**maakt  |
| af**rekenen**   | af**ge**rekend     |
| in**vullen**    | in**ge**vuld       |
| op**lossen**    | op**ge**lost       |

### Voorbeelden uit oefeningen

- Ik heb de kamer **opgeruimd**.
- Anna heeft de soep **klaargemaakt**.
- We hebben het cadeau **ingepakt**.
- Julia heeft het pakje **opengemaakt**.
- Ik heb een nieuwe pinpas **aangevraagd**.
- Ik heb het formulier al **ingevuld**.
- We hebben de afspraak **afgezegd**.
- We hebben alles samen **opgeruimd**.
- De kinderen hebben hun bedden **opgemaakt**.
- Hebben ze het afval al **opgehaald**?
- Hij heeft ons voor zijn feestje **uitgenodigd**.

## 2.23 Voltooide tijd scheidbare werkwoorden met zijn: ik ben uitgestapt

### Regel

Bewegingswerkwoorden met scheidbaar prefix gebruiken **zijn** in de voltooide
tijd. Het ge- komt ook tussen de twee delen:

| Werkwoord       | Voltooide tijd             |
| --------------- | -------------------------- |
| uit**stappen**  | ik **ben** uit**ge**stapt  |
| in**stappen**   | ik **ben** in**ge**stapt   |
| over**stappen** | ik **ben** over**ge**stapt |

### Voorbeelden uit oefeningen

- Ik **ben** op tijd **uitgestapt**.
- Anna **is** op Schiphol **overgestapt**.
- We **zijn** bij het park **ingestapt**.
- Je **bent** bij de verkeerde halte **uitgestapt**.
- Hij **is** op Schiphol **overgestapt**.
- Hoe laat zijn jullie het vliegtuig **ingestapt**?
- We **zijn** gisteren in Amsterdam **uitgestapt**.

## 2.24 Voltooide tijd scheidbare onregelmatige werkwoorden met hebben: ik heb het raam opengedaan

### Regel

Scheidbare onregelmatige werkwoorden: **ge-** komt ook tussen de twee delen,
maar het deelwoord is onregelmatig:

| Werkwoord        | Voltooid deelwoord |
| ---------------- | ------------------ |
| open**doen**     | open**ge**daan     |
| terug**brengen** | terug**ge**bracht  |
| mee**nemen**     | mee**ge**nomen     |
| uit**geven**     | uit**ge**geven     |
| op**schrijven**  | op**ge**schreven   |
| aan**trekken**   | aan**ge**trokken   |
| weg**doen**      | weg**ge**daan      |
| in**schrijven**  | in**ge**schreven   |
| na**denken**     | na**ge**dacht      |
| uit**zoeken**    | uit**ge**zocht     |
| terug**krijgen** | terug**ge**kregen  |

### Voorbeelden uit oefeningen

- Ik heb de deur **opengedaan**.
- We hebben het boek **teruggebracht**.
- Jullie hebben je jas **meegenomen**.
- We hebben te veel geld **uitgegeven**.
- Julia heeft het huiswerk **opgeschreven**.
- Hij heeft zijn zoon bij de basisschool **ingeschreven**.
- We hebben lang over het probleem **nagedacht**.
- Mijn zus heeft veel oude kleren **weggedaan**.
- Ze heeft een mooie ring **uitgezocht**.

## 2.25 Voltooide tijd scheidbare onregelmatige werkwoorden met zijn: ik ben op tijd weggegaan

### Regel

Bewegingswerkwoorden met onregelmatig deelwoord gebruiken **zijn**. Het ge- komt
tussen de twee delen:

| Werkwoord      | Voltooide tijd                  |
| -------------- | ------------------------------- |
| weg**gaan**    | ik **ben** weg**ge**gaan        |
| op**staan**    | ik **ben** op**ge**staan        |
| thuis**komen** | ik **ben** thuis**ge**komen     |
| aan**komen**   | ik **ben** aan**ge**komen       |
| af**vallen**   | ik **ben** af**ge**vallen       |
| mee**gaan**    | ik **ben** mee**ge**gaan        |
| langs**komen** | ik **ben** langs**ge**komen     |
| over**gaan**   | de pijn **is** over**ge**gaan   |
| open**gaan**   | de winkel **is** open**ge**gaan |
| over**steken** | ik **ben** over**ge**stoken     |

### Voorbeelden uit oefeningen

- Ik **ben** op tijd **weggegaan**.
- We **zijn** vroeg **opgestaan**.
- Mijn hoofdpijn **is** vanzelf **overgegaan**.
- De trein **is** in Zwolle **aangekomen**.
- Mijn zus **is** vorig jaar tien kilo **afgevallen**.
- **Zijn** jullie allemaal **meegegaan**?
- De nieuwe winkel **is** gisteren **opengegaan**.
- De kinderen **zijn** de drukke weg **overgestoken**.
- Hij **is** met zijn vriendin **meegegaan**.
- Hoe laat **ben** je **weggegaan**?

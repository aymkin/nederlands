# Woordenlijst — thema 8 · taak 4: Wat moet ik doen?

> Извлечено из `1000050461.pdf` (LINK 0 → A2 © Boom uitgevers Amsterdam, 2019)

Контекст таски: у нового соседа собака лает по ночам, маленький ребёнок часто
плачет, музыка громкая — сосед жалуется и спрашивает совета. Типичная тема
geluidsoverlast (шумовых жалоб) в плотно застроенных НЛ-кварталах.

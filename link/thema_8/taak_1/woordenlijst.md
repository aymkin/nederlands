# Woordenlijst — thema 8 · taak 1: We eten altijd samen

> Извлечено из `1000050458.pdf` (LINK 0 → A2 © Boom uitgevers Amsterdam, 2019)

Контекст таски: соседи по дому пишут профиль для нового жильца — возраст,
привычки (курение, уборка, спорт), что важно в совместной жизни. «Мы всегда едим
вместе» как одно из правил дома.

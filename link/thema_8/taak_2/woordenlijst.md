# Woordenlijst — thema 8 · taak 2: Wanneer begint de cursus?

> Извлечено из `1000050459.pdf` (LINK 0 → A2 © Boom uitgevers Amsterdam, 2019)

Контекст таски: запись на бесплатный курс нидерландского/компьютера в районном
центре (wijkcentrum). Когда стартует группа, куда отправить мейл, что делать,
если попал в лист ожидания — типичная ситуация для нового жителя Нидерландов.

# Woordenlijst — thema 8 · taak 3: Het is een rustige buurt

> Извлечено из `1000050460.pdf` (LINK 0 → A2 © Boom uitgevers Amsterdam, 2019)

Контекст таски: описание тихого района — деревья, парк с детской площадкой,
начальная школа рядом, церкви и мечети, улицы с рядными домами. Жильцы
заговаривают друг с другом на улице, дети играют в парке.

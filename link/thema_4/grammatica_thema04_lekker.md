# Thema 4: Lekker! — Grammatica

## 1.1 Persoonlijke voornaamwoorden als onderwerp: ik, we, je, u, jullie

### Regel

Persoonlijke voornaamwoorden die het onderwerp zijn in de zin:

| Persoon                          | Voornaamwoord |
| -------------------------------- | ------------- |
| 1e persoon enkelvoud             | **ik**        |
| 2e persoon enkelvoud (informeel) | **je**        |
| 2e persoon enkelvoud (formeel)   | **u**         |
| 1e persoon meervoud              | **we**        |
| 2e persoon meervoud              | **jullie**    |

### Voorbeelden uit oefeningen

- **ik** → één persoon die over zichzelf spreekt
- **je** → informeel aanspreekwoord voor één persoon
- **u** → formeel aanspreekwoord voor één persoon
- **we** → groep waarbij de spreker hoort
- **jullie** → groep aanspreken (informeel, meervoud)

## 2.1 Het werkwoord: ik, we + werkwoord

### Regel

| Persoon | Vorm                   |
| ------- | ---------------------- |
| ik      | **werk** (stam)        |
| we      | **werken** (stam + en) |

### Voorbeelden uit oefeningen

- Ik **werk** in Rotterdam.
- We **werken** in Rotterdam.
- Ik **lees** het formulier.
- We **drinken** thee.
- Ik **ga** naar school.
- We **wonen** in een dorp.
- Ik **bel** een vriend.
- We **kopen** brood.

## 3.1 De zin met één werkwoord

### Regel

Een gewone Nederlandse zin heeft de volgorde: | Positie 1 | Positie 2
(werkwoord) | Positie 3+ | |-----------|-----------------------|------------| |
Ik | drink | thee. | | We | drinken | thee. | | Je | drinkt | thee. | | U |
drinkt | thee. | | Jullie | drinken | thee. |

Het werkwoord staat altijd op de **tweede positie** in de zin.

### Voorbeelden uit oefeningen

- Ik **werk** in Rotterdam.
- We **werken** in Rotterdam.
- Jullie **schrijven** een e-mail.
- U **leest** het formulier.
- We **gaan** naar het werk.

## 3.2 De zin: wat is een werkwoord?

### Regel

Een werkwoord beschrijft een actie of toestand.

- Ik **drink** water. → _drink, drinkt, drinken_ zijn werkwoorden.
- Elke zin heeft een werkwoord.

Voorbeelden van werkwoorden: werken, kijken, gaan, hebben, liggen, wachten.

### Voorbeelden uit oefeningen

- Ik **woon** in Amsterdam. → werkwoord: _woon_
- We **spellen** de naam. → werkwoord: _spellen_
- Je **eet** de tomaat. → werkwoord: _eet_
- Jullie **werken** in Utrecht. → werkwoord: _werken_
- U **luistert** naar muziek. → werkwoord: _luistert_

## 4.1 Eén of meer (enkelvoud en meervoud)

### Regel

| Enkelvoud  | Meervoud         |
| ---------- | ---------------- |
| de citroen | de citroen**en** |
| de vrouw   | de vrouw**en**   |
| de appel   | de appel**s**    |
| de jongen  | de jongen**s**   |

Meest voorkomende meervoudsuitgangen: **-en** en **-s**.

### Voorbeelden uit oefeningen

- de dochter → de dochter**s**
- de naam → de nam**en**
- de tomaat → de tomat**en**
- de fles → de flessen
- de telefoon → de telefoon**s**
- de vriend → de vriend**en**
- de vis → de viss**en**
- het brood → de brod**en**
- het meisje → de meisjes

## 8.1 Met en zonder accent: jij – je, wij – we

### Regel

| Zonder accent (normaal gebruik) | Met accent (nadruk) |
| ------------------------------- | ------------------- |
| **je**                          | **jij**             |
| **we**                          | **wij**             |

- **je / we** = normaal gebruik, geen nadruk
- **jij / wij** = met nadruk (contrast of vergelijking)

### Voorbeelden uit oefeningen

- Wat eet **je**? _(gewone vraag)_
- Ik heet Max. Hoe heet **jij**? _(nadruk: jij, niet ik)_
- **We** gaan naar huis. _(gewoon)_
- **Wij** gaan naar huis. Ga **jij** ook? _(nadruk)_
- Eet **je** ook vis?

# Fluent + Link — инструкция, рекомендация, методология

Как использовать связку **курс Link → Fluent** для ежедневного повторения.
`handleiding` (нид.) = руководство, инструкция.

---

## 1. Что это и зачем

Раньше Fluent сам придумывал контент для упражнений. Теперь есть мост
`scripts/fluent_import.py`, который берёт **твой реальный материал Link** (слова
из woordenlijst + грамматику) и заливает его в движок интервального повторения
Fluent. Ежедневное `/fluent-review` крутит именно то, что у тебя на занятиях в
Danner — а не абстрактные слова.

### Два хозяина, две оси

| Ось                         | Кто решает          | Чем управляешь       |
| --------------------------- | ------------------- | -------------------- |
| **Последовательность тем**  | `curriculum.json`   | ты (`--advance`)     |
| **Когда карточка всплывёт** | Fluent / SM-2       | алгоритм (сам)       |

`curriculum.json` решает, **какая тема активна**; SM-2 решает, **когда внутри
неё показать каждую карточку**. Не путай и не пытайся управлять второй осью
вручную — в этом весь смысл интервального повторения.

---

## 2. Команды

Все запускаются из корня проекта. В этом чате можно через префикс `!`.

| Команда                                            | Когда                          |
| -------------------------------------------------- | ------------------------------ |
| `python3 scripts/fluent_import.py --course link`   | один раз при старте новой темы |
| `/fluent-review`                                    | **каждый день**                |
| `python3 scripts/fluent_import.py --course link --check`   | раз в неделю — дозрел ли?  |
| `python3 scripts/fluent_import.py --course link --advance` | когда `--check` сказал ✅   |
| `python3 scripts/fluent_import.py --course link --thema N`  | фокус на теме N (см. ниже) |

### Фокус на конкретной теме

Хочешь прогнать **отдельную** тему, не трогая основной указатель прогресса:

```bash
python3 scripts/fluent_import.py --course link --thema 5            # засеять тему 5
python3 scripts/fluent_import.py --course link --thema 5 --taak 2   # только taak 2
python3 scripts/fluent_import.py --course link --check --thema 5    # её готовность
```

`--thema N` импортирует тему N напрямую — `active` в manifest **не меняется**,
последовательность не сбивается. Удобно подтянуть раннюю тему (4–7) или
забежать вперёд, оставаясь «официально» на своей активной теме. Можно и просто
попросить меня: «проведи сессию по thema 5» — соберу упражнения из её файлов.

## 3. Рекомендованный рабочий цикл

```
старт темы ──► import ──►  /fluent-review ежедневно  ──► --check (раз в нед.)
                              ▲                                  │
                              └────── --advance ◄──── ✅ готов ──┘
```

1. **Старт темы (раз).** `--course link` заливает активную тему. Сейчас активна
   **thema 4** — залита грамматика (51 карточка; woordenlijst у тем 4–7 пока
   нет, поэтому только грамматические cloze).
2. **Каждый день.** `/fluent-review`. 5 дней в неделю минимум — система построена
   вокруг ежедневности, пропуск ломает интервалы.
3. **Раз в неделю.** `--check`. Покажет процент освоенности активной темы.
4. **Переход.** Когда `--check` даёт ✅ (**≥80% карточек на mastery ≥ 3 и ноль
   «красных»**) — `--advance`. Тема помечается `done`, активируется следующая,
   заливается. Старые карточки **остаются** и продолжают всплывать (рециклинг).

## 4. Методология — как заниматься, чтобы это работало

### 4.1. Активное припоминание (active recall)

Печатай ответ **до** того, как увидел правильный. Не подглядывай. Усилие
вспоминания — это и есть то, что переносит слово в долговременную память.
Узнавание («а, точно») слабее производства («сам написал»).

### 4.2. Честность с оценкой

SM-2 работает только на честных сигналах. Вспомнил с трудом — так и скажи
(`quality 3`), не завышай. Завысишь — карточка уйдёт на 2 недели и забудется;
занизишь честно — вернётся завтра и закрепится. Ошибка — это **полезные данные**,
а не провал.

### 4.3. Не копи долги

Лучше 10 карточек каждый день, чем 70 раз в неделю. Пропущенные дни обрушивают
очередь, и кривая забывания съедает прогресс (как у нас уже было — серия
сбросилась после 8-дневной паузы).

### 4.4. Грамматика как продукция

Грамматические карточки — это cloze: `Ik ___ geen vlees eten. → wil`. Они
заставляют **произвести форму**, а не узнать её. Это бьёт ровно по твоим слабым
местам:

| Твой паттерн                  | Что тренирует cloze                       |
| ----------------------------- | ----------------------------------------- |
| порядок слов (глагол в конце) | восстановление позиции глагола            |
| удвоение гласных/согласных    | `wil` (одна `l`), не англ. `will`         |
| `kun` / `kan`                 | выбор формы по подлежащему                |
| formeel / informeel          | `u` vs `je` в контексте                    |
| английская интерференция      | нидерландское написание, не калька        |

### 4.5. Как это сочетается с остальным

- **Anki** = узнавание слов + аудио (оставляешь как есть).
- **Fluent** = продукция + грамматика-в-контексте + трекинг **твоих** ошибок.
- **Занятия в Danner** = новый материал. Прошли тему → `import`/`--advance`,
  и Fluent закрепляет именно её.
- **Daily-план** (`daily/`) = метод Евгения (6 шагов). Fluent-review хорошо
  ложится в утренний/обеденный слот повторения.

## 5. Прогресс по темам

`curriculum.json` хранит порядок и статусы. Ровно одна тема `active`.

| Статус     | Что значит                                       |
| ---------- | ------------------------------------------------ |
| `done`     | позади указателя — не импортируется автоматически |
| `active`   | текущая — её заливает `import`                    |
| `locked`   | впереди — активируется через `--advance`          |

Сейчас: **4** `active`, **5–20** `locked` — идём с темы 4 по порядку, осваивая
и продвигаясь через `--advance`.

## 6. Важные оговорки

- **Темы 4–7 и 13–20 — пока только грамматика** (woordenlijst ещё нет). При их
  импорте будут только грамматические карточки.
- **Идём по порядку с темы 4.** Указатель на `thema_4`; `--advance` ведёт
  4 → 5 → … По мере появления woordenlijst у ранних тем их импорт начнёт давать
  и слова, а не только грамматику.
- **Грамматику правь до импорта темы.** `item_id` грамматики позиционный: вставка
  примера в середину раздела после импорта осиротит карточки. Слова этому не
  подвержены (id по слову).
- **Импорт идемпотентен** — повторный запуск дублей не плодит, перед записью
  делается бэкап в `~/.claude/fluent-data/.backups/`.
- **De Opmaat** пока не подключён — нужен свой `de_opmaat/curriculum.json`.

## 7. Если коротко

Раз в тему — `import`. Каждый день — `/fluent-review`, честно. Раз в неделю —
`--check`. Зелёный свет — `--advance`. Всё остальное (что и когда показать)
сделает SM-2.

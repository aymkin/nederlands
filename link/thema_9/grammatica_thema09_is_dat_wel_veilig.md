# Thema 9: Is Dat Wel Veilig? — Grammatica

## 3.3 De zin: wat is het onderwerp?

### Regel
Het **onderwerp** is degene die de handeling uitvoert. Vraag: **Wie doet het?**

- Ik help je. → Wie helpt? → **ik** = onderwerp
- Je helpt me. → Wie helpt? → **je** = onderwerp
- De docent helpt de kinderen. → Wie helpt? → **de docent** = onderwerp

**Bijna elke zin heeft een onderwerp.**

### Voorbeelden uit oefeningen
- We spellen de naam. → onderwerp: **We**
- De docent schrijft mijn naam. → onderwerp: **De docent**
- De man zoekt een vrouw. → onderwerp: **De man**
- Jullie wachten op me. → onderwerp: **Jullie**
- Ze wachten op jullie. → onderwerp: **Ze**
- Het kind houdt van zijn moeder. → onderwerp: **Het kind**
- De jongens spelen met de voetbal. → onderwerp: **De jongens**

## 3.5 De zin met één of twee werkwoorden

### Regel
Net als bij 3.4: bij twee werkwoorden staat het **tweede werkwoord aan het eind** (infinitief):

| Met één werkwoord | Met twee werkwoorden |
|-------------------|---------------------|
| Ik leer Nederlands. | Ik **wil** Nederlands **leren**. |
| John kijkt tv. | John **gaat** tv **kijken**. |
| We komen morgen niet. | We **kunnen** morgen niet **komen**. |

Het tweede werkwoord (leren, kijken, komen) staat aan het eind.

### Voorbeelden uit oefeningen
- Ik wil je graag **ontmoeten**.
- Anna gaat gauw **verhuizen**.
- De kinderen kunnen niet **fietsen**.
- Sofia kan haar naam **spellen**.
- U moet snel **komen**.
- De bus zal hier **stoppen**.
- Je kan maandag een afspraak **maken**.
- Jullie moeten zachter **praten**.
- Hij wil een nieuwe telefoon **kopen**.

## 7.4 Personen in de zin: volledig overzicht me, je, u, hem, haar, ons, jullie, ze

### Regel (compleet schema object-vormen)
| Onderwerp | Object-vorm |
|-----------|-------------|
| ik | **me** |
| je | **je** |
| u | **u** |
| hij | **hem** |
| ze (vrouw) | **haar** |
| we | **ons** |
| jullie | **jullie** |
| ze (meervoud) | **ze** |

### Voorbeelden uit oefeningen
- Ik heb een vriend. Hij helpt **me**. *(ik → me)*
- Sofia, je bent lief. Ik help **je**. *(je → je)*
- Mevrouw, ik help **u** graag. *(u → u)*
- De vrouw is oud. Ik help **haar**. *(ze → haar)*
- De man is oud. Ik help **hem**. *(hij → hem)*
- We hebben een vriend. Hij helpt **ons**. *(we → ons)*
- Anna en Sofia, ik help **jullie**. *(jullie → jullie)*
- De man en vrouw zijn oud. Ik help **ze**. *(ze → ze)*

## 12.2 Trappen van vergelijking: onregelmatige vormen

### Regel
| Stellende trap | Vergrotende trap | Overtreffende trap |
|---------------|-----------------|-------------------|
| veel | meer (dan) | het meest |
| weinig | minder (dan) | het minst |
| graag | liever (dan) | het liefst |
| goed | beter (dan) | het best |

### Voorbeelden uit oefeningen
- 50 euro is **veel**. 75 euro is **meer** dan 50 euro. 100 euro is **het meest**.
- 1 euro is **weinig**. 50 cent is **minder** dan 1 euro. 10 cent is **het minst**.
- Ik kan **goed** fietsen. Ali fietst **beter** dan ik. Anna fietst **het best**.
- Ik eet **graag** kip. Ali eet **liever** vis dan kip. Anna eet **het liefst** kip.
- Ik drink **liever** koffie dan thee.
- Wie kookt **het best**?

## 12.3 Vergelijking: even groot als, groter dan

### Regel
| Situatie | Constructie |
|----------|-------------|
| gelijkheid | **even** + bijvoeglijk naamwoord + **als** |
| ongelijkheid | bijvoeglijk naamwoord + **er** + **dan** |

### Voorbeelden uit oefeningen
- De sinaasappel is **groter dan** de citroen.
- De sinaasappel is **even groot als** de appel.
- De vis is **duurder dan** de kip.
- De groente is **even duur als** het fruit.
- Mijn keuken is **even groot als** jouw keuken.
- Mijn badkamer is **groter dan** jouw badkamer.
- De trein is **sneller dan** de fiets.
- Een auto is **duurder dan** een fiets.
- Een appel is **even groot als** een sinaasappel.

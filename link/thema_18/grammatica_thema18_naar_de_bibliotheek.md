# Thema 18: Naar de Bibliotheek — Grammatica

## 2.28 Het werkwoord: ik voel me niet lekker (reflexieve werkwoorden)

### Regel

Sommige werkwoorden hebben een **reflexief voornaamwoord** nodig (me, je, zich,
ons):

| Onderwerp          | Reflexief vnw. |
| ------------------ | -------------- |
| ik                 | **me**         |
| je/jij             | **je**         |
| u                  | **zich**       |
| hij/ze (enkelvoud) | **zich**       |
| we/wij             | **ons**        |
| jullie             | **je**         |
| ze (meervoud)      | **zich**       |

Veelgebruikte reflexieve werkwoorden: zich voelen, zich vervelen, zich
herinneren, zich zorgen maken, zich inschrijven, zich aanmelden, zich
ontwikkelen.

### Voorbeelden uit oefeningen

- Ik voel **me** niet lekker.
- Je voelt **je** niet lekker. / Jullie voelen **je** niet lekker.
- We voelen **ons** gezond.
- U voelt **zich** gezond. / Sarah voelt **zich** gezond.
- De kinderen voelen **zich** gezond.
- Ik verveel **me** vaak op zondag.
- Kleine kinderen ontwikkelen **zich** snel.
- Herinner je **je** die vakantie in Turkije nog?
- Meld jullie **je** voor de cursus aan?
- We schrijven **ons** in bij de gemeente.
- David maakt **zich** zorgen over Layla.

## 3.14 De zin met 'omdat', 'als': inversie in de hoofdzin (Omdat ik moe ben, ga ik naar bed.)

### Regel

Als de bijzin met **omdat** of **als** **vooropstaat**, dan geldt inversie in de
hoofdzin (werkwoord vóór onderwerp):

| Bijzin (voorop)                      | +   | Hoofdzin (inversie)    |
| ------------------------------------ | --- | ---------------------- |
| Als ik moe **ben**,                  |     | **ga ik** naar bed.    |
| Omdat ik geen honger **heb**,        |     | **eet ik** niks.       |
| Omdat ik mijn kind moet **ophalen**, |     | **kan ik** niet komen. |

In de bijzin staat het werkwoord altijd **aan het eind**. In de hoofdzin daarna
staat het werkwoord **vóór** het onderwerp (inversie).

### Voorbeelden uit oefeningen

- Als ik moe ben, **ga ik** naar bed.
- Omdat het koud is, **draagt Ali** een dikke trui.
- Omdat het weekend is, **gaan we** naar de film.
- Als je op die drukke weg fietst, **moet je** goed uitkijken.
- Omdat Julia nooit sport, **is ze** niet fit.
- Omdat David vanavond moet werken, **kan hij** niet koken.
- Als de baby geslapen heeft, **gaan we** naar het park.
- Omdat we een auto hebben gekocht, **reizen we** niet meer met de trein.
- Omdat mijn oma is gevallen, **kan ze** niet goed lopen.

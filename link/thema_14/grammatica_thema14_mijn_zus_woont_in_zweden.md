# Thema 14: Mijn Zus Woont in Zweden — Grammatica

## 2.19 Het werkwoord: ik luisterde (onvoltooid verleden tijd — zwakke werkwoorden met -de/-den)

### Regel

Verleden tijd (imperfectum) voor werkwoorden waarvan de stam **niet** eindigt op
een letter uit 't kofschip (t, k, f, s, ch, p):

| Enkelvoud        | Meervoud          |
| ---------------- | ----------------- |
| ik luister**de** | we luisterd**en** |
| je luisterde     | jullie luisterden |
| u luisterde      |                   |
| hij/ze luisterde | ze luisterden     |

Werkwoorden die **-de/-den** gebruiken: luisteren, horen, vertellen, wonen,
leren, bellen, trouwen, zorgen, reageren, betalen, dromen.

### Voorbeelden uit oefeningen

- Ali trouwde vorig jaar met Layla.
- John stuurde een bericht aan me.
- De kinderen voetbalden bij de flat.
- De buren reageerden niet op mijn bericht.
- De reis duurde twee weken.
- Ik belde je niet.
- We woonden in een dorp.
- De kinderen huilden niet veel.
- Mijn ouders belden de politie.
- Oma zorgde voor de kinderen.

## 2.20 Het werkwoord: ik werkte (onvoltooid verleden tijd — zwakke werkwoorden met -te/-ten)

### Regel

Verleden tijd voor werkwoorden waarvan de stam eindigt op een letter uit **'t
kofschip** (t, k, f, s, ch, p):

| Enkelvoud     | Meervoud       |
| ------------- | -------------- |
| ik werk**te** | we werkt**en** |
| je werkte     | jullie werkten |
| hij/ze werkte | ze werkten     |

Werkwoorden die **-te/-ten** gebruiken: werken, pakken, stoppen, maken, fietsen,
roken, kosten, missen, snappen.

### Voorbeelden uit oefeningen

- Sarah stopte in januari met de cursus.
- Mijn oma gebruikte vroeger geen wasmachine.
- Ze pakten hun agenda.
- Ali snapte de opdracht niet.
- Hij pakte snel zijn telefoon.
- Mijn vader werkte ook in het weekend.
- De bus stopte vroeger bij mijn school.
- Fruit kostte vroeger veel minder dan nu.
- Ik maakte vroeger nooit huiswerk.
- We fietsten vorig jaar elke dag naar school.

## 3.9 De zin: Ik werk vandaag niet. Vandaag werk ik niet. (inversie)

### Regel

In het Nederlands staat het **werkwoord altijd op positie 2**. Als een
bijwoordelijke bepaling vooropstaat, schuift het onderwerp naar positie 3:

| Normaal                                               | Met inversie                        |
| ----------------------------------------------------- | ----------------------------------- |
| Ik werk vandaag niet.                                 | Vandaag **werk ik** niet.           |
| We willen in Nederland fietsen.                       | In Nederland **willen we** fietsen. |
| Ik ga boodschappen doen. Daarna wil ik naar de markt. | Daarna **wil ik** naar de markt.    |
| Ik ben moe. Daarom ga ik naar bed.                    | Daarom **ga ik** naar bed.          |

### Voorbeelden uit oefeningen

- Vandaag **ga ik** mijn moeder bellen.
- Vanmiddag **wil ik** boodschappen doen.
- Morgen **wil ik** een nieuwe telefoon bestellen.
- Misschien **moet ik** morgen werken.
- Vanmiddag **gaat het** regenen.
- Gisteren **ben ik** naar de markt geweest.
- Daarna **kunnen we** eten.
- Daarom **ga ik** naar bed.

## 3.11 De zin met 'als' en 'omdat' (bijzin — werkwoord aan het eind)

### Regel

Na **als** (voorwaarde) en **omdat** (reden) staat het werkwoord **aan het eind
van de bijzin**:

| Hoofdzin           | Bijzin                                 |
| ------------------ | -------------------------------------- |
| Ik ga naar bed,    | als ik moe **ben**.                    |
| Ik eet niks,       | omdat ik geen honger **heb**.          |
| Ik kan niet komen, | omdat ik de kinderen moet **ophalen**. |

Bij twee werkwoorden (modaalwerkwoord + infinitief) in de bijzin: **infinitief
staat helemaal aan het eind**.

### Voorbeelden uit oefeningen

- Ik ga naar bed, als ik moe **ben**.
- We eten vis, omdat het gezond **is**.
- Ik bel mijn moeder, omdat ze ziek **is**.
- We willen op vakantie, als we genoeg geld **hebben**.
- Je moet goed uitkijken, als je die drukke weg **oversteekt**.
- Ik ben moe, omdat ik hard heb **gewerkt**.
- We zijn te laat, omdat we de trein hebben **gemist**.
- Gaan jullie naar het park, als de baby geslapen **heeft**?

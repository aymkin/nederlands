## 2.16 Het werkwoord: ik heb gewerkt (voltooide tijd deel 2 — volledig paradigma)

### Regel
Volledig schema van de voltooide tijd met **hebben**:

| Tegenwoordige tijd | Voltooide tijd |
|-------------------|----------------|
| Ik werk. | Ik **heb gewerkt**. |
| Je werkt. | Je **hebt gewerkt**. |
| U werkt. | U **hebt gewerkt**. |
| Hij werkt. | Hij **heeft gewerkt**. |
| Ze werkt. | Ze **heeft gewerkt**. |
| We werken. | We **hebben gewerkt**. |
| Jullie werken. | Jullie **hebben gewerkt**. |
| Ze werken. | Ze **hebben gewerkt**. |

**Let op**: Je schrijft *geluisterd*, maar je zegt: *geluistert* *(uitspraak ≠ spelling).*

### Voorbeelden uit oefeningen
- Ik **heb** een hamburger **gehaald**.
- We **hebben** woensdag **gewerkt**.
- Ze **heeft** de krant **gepakt**.
- De kinderen **hebben** vanmiddag **gespeeld**.
- Hij **heeft** geld **gepind**.
- **Heb** je de e-mail **gecontroleerd**?
- De vakantie **heeft** zes weken **geduurd**.
- We **hebben** de trein **gemist**.
- John **heeft** in het park **gefietst**.
- We **hebben** de baby niet **gehoord**.
- De baby **heeft** gisteravond **gehuild**.
- Het **heeft** vorige week veel **geregend**.

## 3.6 De zin met een vraag: Waar woon je?

### Regel
Bij vragen met een **vraagwoord** (wie, wat, waar, wanneer, hoe, waarom, hoeveel):

| Positie 1 | Positie 2 | Positie 3 | Positie 4 |
|-----------|-----------|-----------|-----------|
| vraagwoord | werkwoord | onderwerp | 2e werkwoord |
| Waar | ben | je? | |
| Waar | ben | je | geweest? |
| Wat | ga | je | doen? |

### Voorbeelden uit oefeningen
- **Waar** is het station?
- **Wat** kan ik voor u doen?
- **Wanneer** gaan jullie trouwen?
- **Waarom** wil je Nederlands leren?
- **Hoe laat** gaan jullie weg?
- **Hoe** heet de vader van David?
- **Waar** gaan jullie morgen naartoe?
- **Waar** heb je de pizza's gehaald?
- **Wat** eten we vanavond?
- **Wanneer** gaat ze op vakantie?
- **Waarom** gaan jullie niet naar school?

## 10.1 Spellen: de naam, de namen (lange klinker)

### Regel
Lange klinkers in gesloten lettergreep (één klinker) vs. open lettergreep (twee klinkers of één + e):

| Uitspraak | Gesloten lettergreep | Open lettergreep |
|-----------|---------------------|-----------------|
| 'aa' | de naam | de nam**en** |
| 'oo' | de boom | de bom**en** |
| 'ee' | ik speel | we spel**en** |
| 'uu' | duur | dur**e** |

**Regel**: In een open lettergreep schrijf je één klinker; in een gesloten lettergreep schrijf je twee.

### Voorbeelden uit oefeningen
- de naam → de nam**en** *(aa → a in open lettergreep)*
- de boom → de bom**en**
- ik speel → we spel**en**
- duur → dur**e**
- ik woon → we won**en**
- De vis is **duur**. → Ik wil de **dure** vis niet.
- Ik **leer** Nederlands. → We **leren** Nederlands.

## 10.2 Spellen: de man, de mannen (korte klinker)

### Regel
Korte klinkers: bij meervoud of verlenging **verdubbel** je de medeklinker:

| Uitspraak | Enkelvoud | Meervoud / verlenging |
|-----------|-----------|----------------------|
| 'a' (kort) | de man | de mann**en** |
| 'o' (kort) | ik stop | we stopp**en** |
| 'e' (kort) | de fles | de fless**en** |
| 'i' (kort) | de kip | de kipp**en** |
| 'u' (kort) | dun | dunn**e** |

### Voorbeelden uit oefeningen
- de man → de mann**en**
- een rok → de rokk**en**
- de fles → de fless**en**
- ik bak → we bakk**en**
- de kip → de kipp**en**
- dun → dunn**e**
- Ali heeft een **dikke** buik. *(dik → dikke)*
- Kan je je adres **spellen**? *(spel → spellen)*
- We stopp**en** voor het stoplicht.

## 10.3 Hoofdletters en leestekens

### Regel

**Punt of vraagteken**: elke zin eindigt met een punt (.) of vraagteken (?):
- We zijn thuis**.**
- Hoe laat zijn jullie thuis**?**

**Hoofdletters**: gebruik hoofdletters voor:
1. Het begin van elke zin
2. Voornamen en achternamen: **David Mulder**
3. Namen van landen en plaatsen: **Nederland**, **Amsterdam**, **Maastricht**

### Voorbeelden uit oefeningen
- **H**oe laat gaan jullie naar de markt?
- **D**e vader van Mohammed heet Ali Yusuf.
- We wonen al vijf jaar in **B**reda.
- **M**ohammed en ik gaan samen naar het feest.
- **N**ederland ligt in **E**uropa.
- Mijn buurman heet **J**ohn **B**oersma.
- Dit is de moeder van **A**nna **J**ansen.
- **A**nna woont in **N**ederland. Ze woont in **M**aastricht.

## 13.1 Het bijvoeglijk naamwoord: het mooie rokje, een mooi rokje

### Regel
Het bijvoeglijk naamwoord krijgt een **-e** in de meeste gevallen, maar **niet** bij:
- **een** + **het**-woord (onbepaald + enkelvoud + het-woord)

| Situatie | Vorm | Voorbeeld |
|----------|------|-----------|
| de-woord, bepaald | **-e** | de mooie tuin |
| de-woord, onbepaald | **-e** | een mooie tuin |
| het-woord, bepaald | **-e** | het mooie meisje |
| het-woord, onbepaald | **geen -e** | een mooi meisje |
| meervoud (altijd) | **-e** | de mooie meisjes |

### Voorbeelden uit oefeningen
- de mooie tuin / **een mooie tuin**
- het mooie meisje / **een mooi meisje**
- de mooie tuinen / de mooie meisjes
- We gaan een **zwarte** tafel kopen.
- Hebben jullie **gezellige** buren?
- Dit is een **lekker** taartje. *(het-woord + een → geen -e)*
- Is de **blauwe** auto van jou?
- Ons dorp heeft een **klein** winkelcentrum. *(het-woord + een → geen -e)*
- We wonen in een **drukke** straat.
- Ik heb een **oud** mobieltje. *(het-woord + een → geen -e)*
- Ik eet een **bruin** broodje. *(het-woord + een → geen -e)*

# Thema 8: In Mijn Buurt — Grammatica

## 2.11 Het werkwoord willen

### Regel (onregelmatig werkwoord)
| Persoon | Vorm |
|---------|------|
| ik | **wil** |
| je | **wilt** |
| u | **wilt** |
| hij/ze (enkelvoud) | **wil** |
| we | **willen** |
| jullie | **willen** |
| ze (meervoud) | **willen** |

**Inversie (vraag)**: Wil **je**?

### Voorbeelden uit oefeningen
- Ik **wil** geen vlees eten.
- Je **wilt** een afspraak bij de dokter maken.
- **Wil** je een pizza of een hamburger?
- Hij **wil** een telefoon kopen.
- U **wilt** een broodje eten.
- Jullie **willen** in de zomer trouwen.
- Ze **willen** hun huis schoonmaken.

## 2.12 Het werkwoord zullen

### Regel (onregelmatig werkwoord)
| Persoon | Vorm |
|---------|------|
| ik | **zal** |
| je | **zal** |
| hij/ze (enkelvoud) | **zal** |
| we | **zullen** |
| jullie | **zullen** |
| ze (meervoud) | **zullen** |

*Gebruik: toekomst, aanbod, veronderstelling*

### Voorbeelden uit oefeningen
- Ik **zal** je helpen.
- **Zal** ik vanavond pasta maken?
- **Zullen** we naar de markt gaan?
- Je **zal** wel moe zijn, denk ik.
- Hij **zal** in september naar school gaan.
- Jullie **zullen** morgen mijn ouders ontmoeten.

## 3.4 De zin met twee werkwoorden

### Regel
Wanneer er twee werkwoorden in een zin zijn, staat het **tweede werkwoord aan het eind** van de zin (in de infinitief):

| Structuur | Voorbeeld |
|-----------|-----------|
| werkwoord 1 | + rest van de zin | + **infinitief** |
| Ik wil | Nederlands | **leren**. |
| Pieter gaat | thuis tv | **kijken**. |
| We kunnen | morgen niet | **komen**. |

### Voorbeelden uit oefeningen
- Ik wil graag in Rotterdam **werken**.
- We kunnen goed **luisteren**.
- Je mag de docent **helpen**.
- Jullie moeten goed **kijken**.
- U kunt bij de kassa **afrekenen**.
- Zal je me **bellen**?
- De kinderen moeten om tien uur thuis **zijn**.
- Ik wil hem iets **vragen**.
- Kan Sarah met de bus naar school **gaan**?

## 7.2 Personen in de zin: geen onderwerp — hem, haar, ze

### Regel
| Persoon/verwijzing | Object-vorm |
|--------------------|-------------|
| man (enkelvoud) | **hem** |
| vrouw (enkelvoud) | **haar** |
| meerdere personen | **ze** |

### Voorbeelden uit oefeningen
- Ali is een man. Ik vind **hem** aardig.
- Layla is een vrouw. Ik vind **haar** aardig.
- Ali en Layla zijn mijn vrienden. Ik vind **ze** aardig.
- Ik begrijp **hem** niet goed.
- We maken een afspraak met **haar**.
- David helpt **ze** vaak.
- Ik bel **ze** elke week.

---

## 7.3 Personen in de zin: ze, hen

### Regel
Bij meervoud als object kan je **ze** of **hen** gebruiken:
- **ze** = normaal gebruik
- **hen** = met nadruk of na een voorzetsel

| Gebruik | Voorbeeld |
|---------|-----------|
| normaal | Ik ga **ze** helpen. |
| met nadruk | De thee is voor ons, de koffie is voor **hen**. |

### Voorbeelden uit oefeningen
- Ik ga **ze** helpen.
- Ik ga **hen** helpen. *(nadruk)*
- De koffie is voor **hen**.
- We zien **ze** elke dag.
- We maken een taart voor **ze**.
- De thee is voor ons, de koffie is voor **hen**.

## 11.2 Geen

### Regel
**Geen** = ontkenning bij zelfstandige naamwoorden (in plaats van *een*, *-*, of hoeveelheid):

| Bevestigend | Ontkennend met 'geen' |
|-------------|----------------------|
| Julia koopt een auto. | Julia koopt **geen** auto. |
| We hebben een supermarkt. | We hebben **geen** supermarkt. |
| Ik heb geld. | Ik heb **geen** geld. |
| Ze eten koekjes. | Ze eten **geen** koekjes. |

**Geen** staat altijd **voor** een ander woord.

### Voorbeelden uit oefeningen
- Ali heeft **geen** fiets.
- Sofia heeft **geen** zussen.
- Het kind eet **geen** vis.
- De man heeft **geen** geld.
- We drinken **geen** alcohol.
- Ik heb **geen** kinderen.
- Ze leest **geen** boeken.
- Mijn broer spreekt **geen** Engels.

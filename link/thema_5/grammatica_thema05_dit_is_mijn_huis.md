# Thema 5: Dit Is Mijn Huis — Grammatica

## 1.2 Persoonlijke voornaamwoorden als onderwerp: hij, ze, ze

### Regel

| Persoon           | Voornaamwoord |
| ----------------- | ------------- |
| man (enkelvoud)   | **hij**       |
| vrouw (enkelvoud) | **ze**        |
| meerdere personen | **ze**        |

### Voorbeelden uit oefeningen

- Dit is Ali. **Hij** zit op de bank.
- Dit is Sarah. **Ze** zit op de bank.
- Dit zijn Ali en Sarah. **Ze** zitten op de bank.

## 2.4 Het werkwoord: hij, ze, ze + werkwoord

### Regel

| Persoon               | Vorm                   |
| --------------------- | ---------------------- |
| hij                   | **werkt** (stam + t)   |
| ze (vrouw, enkelvoud) | **werkt** (stam + t)   |
| ze (meervoud)         | **werken** (stam + en) |

### Voorbeelden uit oefeningen

- **Hij** werkt in Rotterdam.
- **Ze** werkt in Rotterdam.
- **Ze** werken in Rotterdam.
- Ali **leert** Nederlands.
- Ze **leest** het adres.
- Hij **belt** de vrouw.
- Ze **praat** met de kinderen.
- De man en de vrouw **wonen** in Enschede.

## 2.5 Het werkwoord hebben

### Regel (onregelmatig werkwoord)

| Persoon            | Vorm       |
| ------------------ | ---------- |
| ik                 | **heb**    |
| je                 | **hebt**   |
| u                  | **hebt**   |
| hij/ze (enkelvoud) | **heeft**  |
| we                 | **hebben** |
| jullie             | **hebben** |
| ze (meervoud)      | **hebben** |

### Voorbeelden uit oefeningen

- Ik **heb** twee citroenen.
- Je **hebt** een computer en een tv.
- U **hebt** geen internet.
- Ali **heeft** een vriendin.
- We **hebben** een poes.
- Jullie **hebben** een huis en een tuin.
- John en Ali **hebben** een baan.

## 2.6 Het werkwoord zijn

### Regel (onregelmatig werkwoord)

| Persoon            | Vorm     |
| ------------------ | -------- |
| ik                 | **ben**  |
| je                 | **bent** |
| u                  | **bent** |
| hij/ze (enkelvoud) | **is**   |
| we                 | **zijn** |

| ze (meervoud)      | **zijn** |

### Voorbeelden uit oefeningen

- Ik **ben** thuis.

- U **bent** in de supermarkt.
- Ali **is** 30 jaar.
- We **zijn** op de markt.
- Jullie **zijn** in Roermond.

## 6.1 Van wie? mijn, je, uw, zijn, haar

### Regel

| Persoon        | Bezittelijk voornaamwoord |
| -------------- | ------------------------- |
| ik             | **mijn**                  |
| je (informeel) | **je**                    |
| u (formeel)    | **uw**                    |
| hij            | **zijn**                  |
| ze/zij         | **haar**                  |

### Voorbeelden uit oefeningen

- Ik zoek **mijn** tas.
- **Je** tas ligt hier.
- **Uw** tas ligt hier, mevrouw.
- Dit is **zijn** tas. _(tas van Ali)_
- Dit is **haar** tas. _(tas van Anna)_

## 8.2 Met en zonder accent: zij – ze

### Regel

| Zonder accent | Met accent (nadruk) |
| ------------- | ------------------- |
| **ze**        | **zij**             |

- **ze** = normaal gebruik
- **zij** = met nadruk (contrast)

### Voorbeelden uit oefeningen

- **Ze** heet Julia. _(gewoon)_
- **Zij** heet Julia, hij heet Mohamed. _(nadruk: zij, niet hij)_
- **Ze** wonen in Breda.
- **Zij** drinken water, wij drinken thee. _(contrast)_

---

## 8.3 Met en zonder accent: jouw – je

### Regel

| Zonder accent | Met accent (nadruk) |
| ------------- | ------------------- |
| **je**        | **jouw**            |

- **je** = normaal gebruik (meest gebruikt)
- **jouw** = met nadruk (contrast, onderscheid)

### Voorbeelden uit oefeningen

- Julia, **je** tas ligt hier. _(gewoon)_
- Is dit mijn telefoon of **jouw** telefoon? _(nadruk/contrast)_
- Mijn vader en **jouw** vader wonen in Utrecht.
- Wat is **je** achternaam?

# Dutch_CORE2000.pdf против нашего консенсусного ранга — сверка 2026-09-21

Что сверяли: `Dutch_CORE2000.pdf` (лежал в корне репозитория) против списка из
`rangonderzoek.md`. Данные и скрипт: `private/frequentie_pilot/`
(`core2000_compare.py`, `core2000_useful.json`).

## 0. Что это за файл

DutchPod101 / Innovative Language, «2000 Core Words and Phrases», InDesign 21.0,
дата создания PDF 2025-11-04. Рекламный бесплатный ebook: 10 глав по ~200
записей, колонки «Vocabulary | Sample Sentence», нидерландский + **английский**
(русского нет). Аудио в PDF нет — оно продаётся отдельно.

Извлечено 1998 записей из 2000 (номера 1400 и 1826 отсутствуют в самом PDF).
Разбор по координатам слов (`pdftotext -bbox-layout`), а не по layout-тексту:
при переносах примеров строки двух соседних записей слипаются, и построчный
парсер терял границу.

## 2. Решающее число — покрытие текста

Сравнение при **равном** числе единиц, на корпусе субтитров (258 млн токенов),
по словоформам:

| Набор                          | Покрытие |
| ------------------------------ | -------- |
| CORE2000, 1659 лемм-заголовков | 24,5 %   |
| наш консенсусный топ-1659      | 87,5 %   |
| наш консенсусный топ-500       | 80,1 %   |

Разрыв в 63 пункта при одинаковом объёме зубрёжки. Причина видна сразу: из
нашего топ-100 **67 лемм** не заведены в CORE2000 отдельной карточкой, а 31 не
встречается в нём вообще — `ze`, `hij`, `we`, `maar`, `die`, `als`, `naar`,
`moeten`, `dan`, `ook`, `weten`, `nog`, `zo`, `al`, `ons`, `of`, `door`, `deze`,
`dus`, `mens`, `alleen`, `iets`, `ander`, `toch`, `leven`, `blijven`, `tegen`.

CORE2000 — **номенклатура**: существительные, которые можно нарисовать. Наш
список — **частотное ядро**: служебный каркас плюс абстрактные глаголы. Это
разные жанры списков, а не разные версии одного.

## 4. Качество материала

Список переведён с общего для всех языков DutchPod101 шаблона, и это видно:

| Дефект                                    | Сколько |
| ----------------------------------------- | ------- |
| заголовок не встречается в корпусе вообще | 22      |
| «пример» — не предложение, а обрывок      | 366     |
| пример не содержит заголовочного слова    | 78      |
| повтор заголовка целиком                  | 74      |
| числительные отдельными карточками        | 64      |

Несуществующие слова — кальки с английского оригинала: `vertrektgate`,
`boardingticket`, `wekoproep`, `insignificant`, `potloodlood`, `schoolstoel`.
Обрывок вместо примера выглядит так: `jaar` → «een kalenderjaar». Пример без
заголовочного слова — `bewaren` → «Het is niet makkelijk om steeds met nieuwe
ideeën te komen.». Повторяются `perzik`, `voet`, `hoe gaat het?`; числительные
заведены поштучно (`vijfenvijftig`, `zevenduizend`, `honderdeen`). Отдельно:
устаревшая орфография `produktie` (до реформы 1996) и `Fahrenheit` записью №12 —
в метрической стране.

Ошибки в самих карточках: `Het gaat goed me me.` (№1068),
`Met opa wil over een jaar met pensioen.` (№400),
`van de rekening van de rekening` (№326).

Хвост 1986–2000 — не лексика: Efteling, Keukenhof, Anne Frank Huis, Van Gogh
Museum, плюс названия романов (`Hersenschimmen`, `Publieke Werken`). Ещё раньше
идут бренды: Senseo, Bols, Spa rood, Arla karnemelk.

## 5. Что берём

**5.1. 230 «нужных» записей как источник примеров, не как список слов.** Слова у
нас уже отобраны и отранжированы; чего нет — готовых нидерландских предложений
под них. 183 записи дают предложение сразу. Работы на карточку: перевести на
русский (английский в файле есть, но база у нас русская) и вычитать. Файл:
`private/frequentie_pilot/core2000_useful.json`, отсортирован по нашему рангу.

**5.2. ~65 фраз как отдельный маленький набор.** Наш ранг лемма-ориентирован и
фразы не видит вообще — это его слепое пятно, а CORE2000 их даёт с примером:
`nodig hebben`, `een hekel hebben aan`, `te laat komen`, `wakker worden`,
`geboren worden`, `zorgen maken`, `oneens zijn`, `uit eten gaan`,
`Hoe laat is het?`, `Waar kom je vandaan?`. Вычитать обязательно — среди них
есть и мусор (`Tijd niet gezien.` — калька с «long time no see», так не
говорят).

**5.3. Тематические кластеры под verhalen.** Записи «вне ядра» бесполезны для
частотного плана, но это готовые тематические гнёзда (овощи, животные, одежда,
части тела, аэропорт) с примерами — материал для историй и для Юлиных заданий,
где нужна конкретная предметная лексика, а не частота.

## 6. Что не берём

- Список как порядок изучения — он не частотный (§1, §2).
- Числительные, бренды, достопримечательности, названия романов (~250 записей).
- 22 несуществующих слова и 366 обрывков вместо примеров — без вычитки в колоду
  ничего не идёт.
- Замену нашему списку. Один и тот же объём зубрёжки даёт 24,5 % против 87,5 %
  покрытия текста.

## 7. Оговорки

1. «Уже знаем» (698) — потолок, а не факт: множество выученного строится по всем
   словам строки Anki-экспорта, включая слова из примеров. При строгом разборе
   (только первое поле карточки) пробел топ-3000 растёт с 1705 до 1812 лемм, то
   есть «нужного» в CORE2000 было бы чуть больше 230.
2. Покрытие меряется на том же корпусе субтитров, из которого построен наш ранг
   — это льстит нашему списку. Разрыв в 63 пункта слишком велик, чтобы
   объясниться этим смещением, но точная цифра завышена.
3. Лемматизация `simplemma` даёт артефакты на композитах; часть из 78 «примеров
   без заголовочного слова» — на деле отделяемые глаголы (`uittrekken` → «Trek …
   uit»), которые лемматизатор не склеил.
4. Два номера (1400, 1826) в PDF отсутствуют; 10 заголовков содержат мягкий
   перенос (`computerweten- schap`) — артефакт извлечения, не исходника.
